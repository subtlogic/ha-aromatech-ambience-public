# 0.6.0a1 — estimated usage and schedule alpha

This opt-in alpha adds a persistent **Estimated sprays** counter based on reported
intensity timings, enabled schedules and compatible device observations. It also
adds estimated active spray time, observed/unknown coverage and bottle-weight
checkpoints for estimating remaining oil.

Counts start after installation; historical activity and personal measurements
are not automatically imported. Unobserved periods are not counted as confirmed
usage. Two weight checkpoints over a fully observed operating interval can learn
a consumption rate. Restarting or changing integration options requires a fresh
weight before remaining-oil estimates become available again.

Schedule parsing now retains minutes, all slots and opaque bytes. Existing entity
IDs and first-slot controls remain. Indexed append/edit/delete actions are behind
an experimental option, disabled by default; extended writes require hardware
validation. Firmware checking and OTA remain deferred.

## Install

Select `0.6.0a1` through HACS Redownload/version selection, allowing prerelease
versions if needed, then restart Home Assistant. Leave experimental schedule
writes disabled for the initial counting test. The attached component ZIP is an
alternative manual-install artifact: extract `aromatech_ambience` into
`config/custom_components/`, replacing the integration folder, then restart.

For rollback, reinstall your previous version and restart Home Assistant. This
alpha does not perform a configuration-entry migration.

## Validation and limits

100 local tests passed, including service schemas in the dependency-equipped
environment. Compilation, metadata and scope checks passed; Claude peer review
findings were fixed and regression-tested. Remote CI is checked against the
published candidate before this release is made available. No full live-HA smoke
test or extended-schedule hardware validation is claimed by this release.

This is an estimate model, not measured spray telemetry. Startup bursts, missed
observations and unknown operating behavior can affect accuracy. Stable release
remains pending further testing and weight comparison.
