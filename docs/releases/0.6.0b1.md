# 0.6.0b1 — bottle-management beta

This opt-in prerelease builds on `0.6.0a1` with per-diffuser scent, bottle and fill
inventory, native management forms and conditional refill forecasts. It is not a
stable release or a hardware oil-level measurement.

## Changes

- Manage scents and bottles through the integration's Configure menu: create,
  edit, install/store, weigh/correct, refill/change scent, archive/restore,
  confirmed permanent deletion and alert acknowledgement. Selectors show names
  plus ID suffixes; no raw JSON input is required.
- Preserve names independently of identity and counts. Refills append history;
  stored partial bottles retain their balances. Lifetime counters continue
  across swaps, while each fill receives only new usage when active.
- Add per-fill rate calibration, remaining percentage, daily grams, conditional
  days remaining, active bottle/scent and refill status. Scent defaults seed
  future fills; changing a default does not rewrite an existing fill's rate.
- Retain bounded mass uncertainty for brief gaps using unknown seconds multiplied
  by the fill's grams-per-active-second rate. Show a range; request weighing
  when unbounded or when only its lower bound reaches the low-oil threshold. Unknown
  time remains excluded from counted usage and calibration coverage.
- Preserve stored bottle balances across restart; active downtime adds
  uncertainty. Alpha totals and legacy checkpoints remain in their original
  separate store, without retroactively assigning history to new bottles.
- Optional persistent HA refill notifications default off and support durable
  acknowledgement. Inventory changes do not reload the entry. Notification and
  forecast settings apply live; heartbeat/experimental settings still reload.

## Before testing

Back up Home Assistant. In HACS, select this repository's `0.6.0b1` prerelease
through Redownload, then restart HA. Keep experimental schedule writes off unless
deliberately performing hardware acceptance tests.

Turn Scenting off manually before physically installing or storing a bottle;
the action requires a fresh power-off report. No inventory operation or refill
alert automatically switches the diffuser off or back on. Read
[Bottle management](../BOTTLES.md) before setting up inventory or correcting a
measurement.

Older integration versions do not expose the beta inventory store. Rollback does
not convert inventory records into alpha weight checkpoints. Existing lifetime
totals and entity IDs are retained; historical recorder usage is not imported.

## Validation and limits

Automated tests cover native form validation/routing, inventory and fill history,
usage attribution, storage and forecast behavior. HA-facing tests use isolated
stubs and do not establish live frontend compatibility or physical device
acceptance. The delivery validation record belongs in [VALIDATION.md](../VALIDATION.md).

Rate reuse for a scent and scaling across intensity levels remain assumptions.
Days remaining assumes the recurring weekly schedule continues. No personal
weights or fixed consumption rates are bundled. Multi-slot schedule writes,
append/delete and minute-level behavior still need hardware acceptance. Firmware
checking, OTA and stable release promotion remain outside this beta.
