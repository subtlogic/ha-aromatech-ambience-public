# 0.6.2 — Current dashboard examples

This patch release refreshes the dashboard screenshot and its README references.
The examples ZIP now includes the current Bubble popup with oil remaining, days
remaining, connection health and simplified controls. Screenshot values are
illustrative, not measurements from a user's home.

Runtime behavior is unchanged from 0.6.1: the approximate 4 mg/5 s default,
30/60/120 bottle presets, optional weighing and diagnostic entity choices remain.
There is no new storage migration or calibration change. See the
[0.6.1 notes](0.6.1.md) for feature details, estimate limitations and rollback
requirements when upgrading from older betas. Experimental controls remain opt-in.

Update through HACS and restart Home Assistant, or extract the integration ZIP
into `config/custom_components/aromatech_ambience/`. The separate examples ZIP
contains optional dashboard files; an integration update does not replace your
dashboard or change diffuser settings.

Validation: full Python and frontend suites, version/JSON/YAML checks and exact
release-source tests, HACS and hassfest must pass before publication. The screenshot
was captured and visually checked using the current example, with device writes
blocked. This documentation update adds no new physical-device acceptance claim.
