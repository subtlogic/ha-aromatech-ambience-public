# 0.6.0b3 — spray-time consumption and experimental 24-hour schedule

This beta fixes usage counters that could stall when lighting automation repeatedly
updated the diffuser. Light and sound commands now preserve the scenting estimation
window; power/schedule changes, failed observations and restarts retain conservative
handling. Previously missed consumption is not reconstructed.

## Consumption

- New bottle sensors expose accumulated estimated spray time and oil consumed.
- A new mg-per-spraying-second sensor exposes the fill's current estimated rate,
  with rate provenance and equivalent five-second dose in its attributes.
- Consumption uses estimated active pump seconds, not intensity-number multiples.
  Each level's reported spray/pause timings determine the active time.
- Existing bottles, weighings, balances, counter IDs and storage formats remain
  intact. A common flow rate across burst lengths remains a calibration assumption.

## Experimental 24-hour schedule

Enable **Experimental schedule writes** in integration options to use the native
**Set 24-hour schedule** button. It writes the app's 08:00–08:00 all-day encoding
to slot one, enables all weekdays and retains intensity and opaque slot fields.
It does not turn scenting on or remove other schedules. Conflicting enabled slots
are rejected. To return to timed use, edit the start/end controls.

Normal spray/pause cycles continue; this does not hold the pump continuously on.
App behavior and encoding are established, but physical full-day operation is not
yet validated. Readback verifies retained settings, not spraying across midnight.
The option therefore remains experimental and disabled by default.

## Install and validation

Select **0.6.0b3** in HACS prereleases, download, then restart Home Assistant.
The attached integration ZIP is available for manual installation. Installing does
not activate the full-day preset or change your level/schedule. Dashboard examples
from 0.6.0b2 remain usable; no dashboard changes are installed automatically.

Validation: 197 Python tests with voluptuous, 19 frontend tests, and exact-commit
GitHub tests, HACS and hassfest checks are required before publication. HA runtime
and hardware acceptance are separate from these offline checks.

Estimates are not physical spray telemetry. Observation gaps and powered-on periods
outside modeled schedule windows remain uncertain; these can prevent automatic
weight calibration. Stable promotion, firmware checking and historical backfill
are not part of this beta.
