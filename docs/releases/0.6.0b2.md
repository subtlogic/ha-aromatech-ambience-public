# 0.6.0b2 — Bubble dashboard examples

This prerelease adds a complete, reusable Bubble dashboard example and an
optional scent/bottle management resource. Integration behavior is unchanged
from 0.6.0b1.

- Bubble summary with scent, intensity, estimated remaining percentage, status
  colour/text and separate scenting power state.
- AromaTech popup with Bubble styling, native estimate rows and existing
  scenting, light and first-slot schedule controls.
- Management popup for scent/bottle creation, editing, weighing, correction,
  refill, archive/restore, confirmed deletion and install/store workflows.
- Setup instructions and entity-ID placeholders for other installations.

## Install

For the integration, select **0.6.0b2** in HACS prereleases, download and restart
HA. The integration ZIP is also attached for manual installation.

The dashboard is **optional and installed separately**. Download the attached
dashboard-examples ZIP, or use the
[example setup guide](https://github.com/subtlogic/ha-aromatech-ambience-public/blob/main/examples/README.md#beta-bubble-dashboard-and-bottle-management).
Install Bubble Card, copy/register the included management module, replace the
entity IDs and config-entry placeholder, then add the complete YAML stack.
Updating the integration does not alter existing dashboards or register resources.

The dashboard also works with 0.6.0b1; upgrading solely for the example is optional.
The existing core-card example is retained. Dashboard removal leaves the inventory
intact, and native integration Configure forms remain available.

## Validation and limits

The management resource has 19 passing focused tests and comes from the
desktop/mobile HA-tested panel. Generic YAML, navigation, resource parity and
relative links are validated. Personal IDs and measurements are not bundled.
Physical multi-slot writes still need device acceptance and remain experimental.
This dashboard edits only the first schedule slot; it is not a multi-slot editor.
Historical spray-count import, firmware checking and stable promotion are not
part of this release. Oil amounts and remaining days remain estimates.
