# Remaining acceptance work

Single-slot operation has been exercised on one Ambience. Extended scheduling
and Always on remain experimental, opt-in controls. Offline tests do not prove
acceptance by every hardware or firmware revision.

Pending authorized hardware checks include minute values, append/edit/delete,
empty-list recovery, four/five-slot writes, full-list readback and weekday order.
Calibration needs real paired weighings with known coverage. The default
4 mg per 5 seconds and nominal bottle sizes are estimates, not universal rates.

Firmware discovery and OTA installation are outside the current scope.
