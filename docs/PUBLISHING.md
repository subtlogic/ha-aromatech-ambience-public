# Public distribution

This repository contains reviewed distribution snapshots of the integration,
user documentation, examples and regression tests. Development and research
history are maintained separately. Do not merge development history into this
repository: export an explicit list of reviewed files instead.

Before publication, inspect the complete snapshot, run the Python and frontend
tests, and pass HACS and hassfest checks. Exclude research notes, decompiled
materials, raw capture files, private logs and development-session records.
Protocol implementation and regression fixtures remain necessary for the
integration to operate and be maintained.

A public snapshot is not a legal clearance or a claim of clean-room development.
Changes in publication history do not change installed devices or stored oil
inventory. Previous feature notes remain useful for compatibility and rollback.
