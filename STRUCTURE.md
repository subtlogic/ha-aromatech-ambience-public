# Repository structure

- `custom_components/aromatech_ambience/`: Home Assistant integration.
- `tests/`: offline regression tests.
- `docs/BOTTLES.md`: bottle setup, estimates and weighing.
- `docs/DEVELOPMENT_PLAN.md`: remaining acceptance work.
- `docs/VALIDATION.md`: validation commands and limitations.
- `docs/PUBLISHING.md`: public distribution boundary.
- `examples/`: optional dashboards, screenshots and automations.
- `CHANGELOG.md` and `docs/releases/`: feature history and compatibility notes.

There is no build backend. Install the integration directory into Home Assistant.
